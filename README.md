# 캡스톤디자인 진행판

스마트팩토리과 3학년 캡스톤 디자인(프로젝트 수업)의 **15차시 진행을 기록하는 도구**입니다.
문제를 푸는 학습도구가 아니라, 팀이 무엇을 언제 냈는지·AI를 어떻게 썼는지를 남기는 판입니다.

- 주소 : https://hongyul67-cpu.github.io/capstone-master/
- 대상 : 특성화고 3학년 (스마트팩토리과) · 1학기 전체 약 16주 · 50분 × 15차시 · 2~3인 팀
- 연계 : AI 활용 리터러시 수업(`ai-step-master`)과 병행하는 2번 수업
- 만든 날 : 2026-09-03

## 화면 여섯

| 탭 | 무엇 |
|---|---|
| 📋 수업 안내 | 수업 목표 · 마일스톤 6단계 · 주제 정하는 순서 · 역할 가이드 · 발표 필수 슬라이드 · 유의사항 |
| 🗓️ 주차 진행판 | 15차시를 그대로 옮긴 카드. 차시마다 단계별 활동과 **산출물 체크 → 제출** |
| 🧑‍🤝‍🧑 팀 · 역할 | 팀명 · 주제 · 3인 역할과 「내가 AI를 어떻게 쓸지」 1줄 → 역할 분담표 제출 · 인쇄 |
| 🤖 AI 활용 로그 | 문제 → 프롬프트 → 답변 → **AI가 틀린 부분** → 최종 해결, 다섯 칸을 누적 기록 → 제출 · 인쇄 |
| 🎤 발표 상호평가 | 14·15차시 동료 평가표. 다섯 기준 + 좋은 점 · 조언 → 팀마다 한 번씩 제출 |
| 📊 평가 기준 | 지도안 Ⅶ 배점표(100점) 그대로 + 교사 채점표(이 기기 저장) · 인쇄 |

기록은 이 기기(localStorage)에 남고, 제출은 `collector.js` 로 선생님 시트에 쌓입니다.
제출 값은 정답률이 아니라 **적어야 할 칸을 얼마나 채웠는가(작성 충실도)** 입니다.
그래서 시트 열 이름을 `labels` 로 바꿔 보냅니다 — 점수→충실도(%) · 정답수→작성한 항목 ·
총문항→필요 항목 · 틀린 문제→기록 요약·빠진 항목.

## 고칠 곳

`index.html` 위쪽 데이터 배열만 고치면 됩니다.

| 배열 | 무엇 |
|---|---|
| `MS` | 마일스톤 6단계 |
| `GOALS` · `EXPLORE` · `ROLES` · `SLIDES` · `SCORE` · `CAUTION` | 지도안 Ⅱ·Ⅳ·Ⅴ·Ⅵ·Ⅶ·Ⅷ |
| `SESSIONS` | **15차시 전문** (차시 · 시기 · 마일스톤 · 학습목표 · 산출물 · 단계별 교사/학생 활동) |
| `PEER` · `LOGF` | 상호평가 항목 5 · AI 로그 다섯 칸 |

## 원자료

`업무폴더\01_수업\2026_수업\3학년 프로젝트 수업\` 의 두 문서입니다.

- `2번_캡스톤디자인_지도안.docx` — 목표 · 마일스톤 · 주제 탐색 · 역할 · 발표 요건 · 평가 기준 · 유의사항

교사가 직접 쓴 지도안이라 **교재 저작물이 아니고, 암호 잠금 없이 공개 배포**합니다.
문구는 지도안 표현을 그대로 옮겼습니다. 임의로 바꾸지 마세요.
